# TAMBAYAN — Community Skill & Resource Sharing Portal

TAMBAYAN is a neighborhood mutual-aid platform where residents can post skills or resources they can offer (tutoring, home repairs, tool lending) or request help from neighbors.

## Core Feature Implemented (Project Development 2)
- **Skill / Resource Listing (Full Vertical Slice)**:
  - **Create**: Logged-in residents can post new skill/resource offers or needs with validation (title length, duplicate open title check, description length).
  - **Read & Search**: Community feed with keyword search (`title`, `description`, `location`) and filters for listing type, category, and status, plus a dedicated **My Listings** view.
  - **Update**: Listing owners can edit their own listings and toggle status between `Open` and `Fulfilled`.
  - **Delete**: Owners can delete their own posts, and administrators can moderate/remove inappropriate listings from the Admin Dashboard.

## Standard Features (Project Development 1)
- Account Registration (`Resident` and `Admin` roles)
- Login / Logout
- Role-Based Dashboards (Resident Dashboard & Admin Dashboard)
- User Profile Viewing and Editing
